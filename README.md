### 📖 내용
이 프로젝트는 개발자들이 자신들의 아이디어를 공유하고 협업하여 자신들의 아이디어를 실행 시킬 수 있도록 돕는 플랫폼입니다. 

개발자는 팀원을 모집하고, 프로젝트를 진행하며, 하루 일정을 기록하고 관리할 수 있습니다. 

이를 통해 팀원들이 함께 목표를 설정하고, 일정을 하나씩 완료해 나가며 프로젝트를 성공적으로 이끌어 갈 수 있도록 지원합니다.

### 🙋‍♂️ 역할
1) ERD를 사용하여 데이터베이스를 설계하였습니다.

2) RESTful 설계 원칙을 준수하여 API를 개발해 클라이언트와 서버 간의 통신을 구현했습니다.

3) Swagger로 API 문서를 자동화하여 개발 편의성을 높였습니다.

4) AWS S3를 활용해 이미지 파일 저장소를 구축했습니다.

5) 스케줄러를 활용하여 주기적인 자동화 작업을 구현했습니다.

6) SMTP를 이용한 메일 전송 시, Async 어노테이션을 사용해 비동기 처리를 적용했습니다.

### 👨🏼‍💻 성과 & 배운점
1) 데이터베이스 설계

ERD를 활용한 데이터베이스 설계와 MySQL 관리로 데이터를 효율적으로 저장하고 조회할 수 있는 구조를 구현했습니다.

2) 효율적인 협업 환경 구축

Swagger를 활용해 API 문서를 자동화함으로써 클라이언트 개발자와의 소통이 원활해졌으며, 개발 속도를 높이고 오류를 줄일 수 있었습니다.

3) RESTful API 설계 및 구현 역량 강화

RESTful 설계 원칙을 준수하며 API를 개발한 경험을 통해 클라이언트-서버 간의 효율적이고 확장 가능한 통신 방식을 구축할 수 있었습니다.
